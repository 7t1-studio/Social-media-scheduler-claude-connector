# Privacy

So-me Studio’s full privacy policy is published at:

**https://so-me.studio/privacy-policy**

## MCP-specific note

When you connect this MCP server (via Claude Directory OAuth, ChatGPT plugin OAuth, or a custom connector with an `X-API-Key`), the client may send tool calls that read or change data in your so-me.studio workspace — for example posts, drafts, media metadata, inbox conversations, analytics summaries, and account settings you already store with us.

- Tool requests are authenticated as your user/tenant (API key or OAuth token).
- We process MCP traffic to fulfill those tools and to enforce plan limits, rate limits, and security logging.
- We do not use your social content from MCP calls to train third-party foundation models.
- You control which clients hold credentials; revoke API keys or disconnect OAuth at any time in So-me Studio settings.

For categories of personal data, retention, and your rights, rely on the main [Privacy Policy](https://so-me.studio/privacy-policy).
