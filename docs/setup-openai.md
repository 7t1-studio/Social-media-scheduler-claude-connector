# ChatGPT

The ChatGPT and Codex plugin for Social media studio lives in its own repository:

**https://github.com/7t1-studio/so-me-studio-chatgpt-plugin**

It connects to `https://api.so-me.studio/mcp/posting`, which carries the same 28 posting tools as the Claude endpoint `https://api.so-me.studio/mcp/claude`. The two endpoints differ only in how they ask for sign-in: the ChatGPT endpoint follows OpenAI's per-tool authentication pattern, and the Claude endpoint answers HTTP `401` so that Claude starts OAuth.
